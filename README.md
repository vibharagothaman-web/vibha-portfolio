# Vibha Ragothaman — Marketing Portfolio

A lightweight, responsive portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally

From this directory:

```sh
python3 -m http.server 4173
```

If Python is unavailable, any static file server will work. You can also open `index.html` directly, though the localhost server is preferred.
